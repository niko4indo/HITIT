HITIT 安卓安装包（PWA 网页应用）

本目录是可部署的静态网页包。Android 11+ 可用 Chrome 安装为主屏幕应用；需要通过 HTTPS 网站访问，不能直接从 file:// 文件路径安装。

发布步骤（GitHub Pages）：
1. 在 GitHub 新建仓库，把本压缩包内所有文件解压后上传到仓库根目录。
2. 打开仓库 Settings > Pages。
3. Build and deployment 选择 Deploy from a branch；选择 main 分支和 /(root)，保存。
4. 发布完成后，用安卓 Chrome 打开 Pages 给出的 HTTPS 地址。
5. 在 Chrome 菜单中点“安装应用”或“添加到主屏幕”。首次打开需要联网；之后 service worker 会缓存应用文件，离线也能启动。

数据说明：
- 记账数据保存在手机浏览器/已安装应用的本地存储，不会因为部署网页而自动同步到电脑。
- 迁移记录：在旧设备的数据页导出 CSV，在手机数据页导入 CSV。预算、汇率和项目设置需在手机上重新设置。
- 请勿把含有个人账目数据的文件上传到公开仓库；这个网页包只包含应用程序代码。
- 需要备份账目时，定期从数据页导出 CSV。
